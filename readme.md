# 과제 알리미

학교 Google 계정으로 과제·공지·제출 현황을 관리하는 Express/MySQL 앱입니다. 2026-11-12에 전체 화면을 다시 디자인하고 GitHub Pages 화면 + 맥북 서버 분리 운영을 구현했습니다.

## 화면

- 초록색 포인트의 반응형 대시보드, 마감 달력, 검색·상태 필터, 제출 현황
- 과제 등록·내 등록 과제, 학년/반 공지, 프로필·화면 모드·관리자 설정
- 학교 계정 로그인과 관리자 반 소속 승인
- 라이트·다크모드, 키보드 조작, 모바일 한 열 배치

## GitHub Pages + 맥북

[설치·배포 안내](docs/GITHUB_PAGES_MAC.md)를 따라 실제 Google 웹 클라이언트 ID, API HTTPS 주소, 운영자 학교 이메일을 설정합니다. 현재 소스에 운영 비밀키나 데이터는 들어 있지 않습니다.

- Pages 빌드는 `web/src`의 허용된 프런트 파일만 배포합니다.
- 맥북의 Express/MySQL/첨부파일은 HTTPS 터널 뒤에서 실행합니다.
- 도메인이 없는 `github.io` 구성에는 타사 쿠키에 의존하지 않는 1시간 Bearer 세션을 사용합니다.
- 같은 출처의 기존 Express 배포는 기본 쿠키 방식으로 유지됩니다.

## 보안

Google ID 토큰과 학교 Workspace를 서버에서 검증하고 실제 DB 권한을 매 요청 확인합니다. 관리자 이메일은 명시한 목록만 사용합니다. 학생의 반 소속은 관리자 승인이 필요합니다.

분리 운영에서는 정확한 프런트 Origin만 허용하고 CORS 프리플라이트·CSRF 검증을 적용합니다. 단기 토큰은 탭 저장소에만 두며, 로그아웃 시 취소하고 서버 재시작 시 무효화합니다. 비공개 이미지는 인증 요청으로 읽어 Blob으로 표시합니다. 학생별 세션 한도와 전체 세션 용량 제한이 있습니다.

Pages에는 CSP·리퍼러 정책을 넣고 iframe 안의 인증 요청을 차단합니다. 첨부파일은 경로·파일 형식·용량·과제 열람 권한을 확인합니다. SQL은 매개변수를 사용합니다. `.env*`, DB·백업·이미지·비밀키는 공개 산출물에서 제외합니다.

`body-parser`와 `qs`의 확인된 서비스 거부 취약점을 패치했습니다. AI 챗봇 원본은 주석으로 보관하며 관련 실행 경로는 비활성화 상태입니다.

## 검증

Node.js 24에서 다음을 실행합니다.

```sh
cd web
npm ci --ignore-scripts
npm test
npm run check
npm audit --omit=dev
cd ..
node --test scripts/configure-mac.test.mjs
```

자동 테스트는 임시 HTTP 서버와 DB·Google 대역을 사용합니다. 실제 학교 Google 로그인, 운영자 승인, 운영 DB 이전, 외부 HTTPS 가동 상태는 실제 계정과 서버에서 별도로 확인해야 합니다. 보안 점검이나 취약점 검사 0건이 미발견 취약점까지 없음을 보증하지는 않습니다.
