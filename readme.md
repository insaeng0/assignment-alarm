# 과제 알리미

학교 Google 계정으로 과제·공지·제출 현황을 관리하는 Express/MySQL 앱입니다. 화면은 GitHub Pages에서, 서버·DB·첨부파일은 Raspberry Pi 4에서 실행하고 고정 Cloudflare Tunnel과 Workers VPC로 연결합니다.

## 화면

- 초록색 포인트의 반응형 대시보드, 마감 달력, 검색·상태 필터, 제출 현황
- 과제 등록·내 등록 과제, 학년/반 공지, 프로필·화면 모드·관리자 설정
- 학교 계정 로그인과 학년·반 선택
- 라이트·다크모드, 키보드 조작, 모바일 한 열 배치

## GitHub Pages + Raspberry Pi 4

[설치·운영 안내](docs/RASPBERRY_PI.md)를 참고하세요. 현재 소스에 운영 비밀키나 데이터는 들어 있지 않습니다. 이전 맥북 구성은 [과거 운영 기록](docs/GITHUB_PAGES_MAC.md)으로 보관하며 현재 Pi 운영에는 사용하지 않습니다.

- Pages 빌드는 `web/src`의 허용된 프런트 파일만 배포합니다.
- 라즈베리파이의 Express/MySQL/첨부파일은 고정 Cloudflare Tunnel과 Workers VPC HTTPS 주소 뒤에서 실행합니다.
- 도메인이 없는 `github.io` 구성에는 타사 쿠키에 의존하지 않는 단기 Bearer 인증과 자동 갱신 세션을 사용합니다.
- 같은 출처의 기존 Express 배포는 기본 쿠키 방식으로 유지됩니다.

## 보안

Google ID 토큰과 학교 Workspace를 서버에서 검증하고 실제 DB 권한을 매 요청 확인합니다. 관리자 이메일은 명시한 목록과 선택적으로 켠 `teacher숫자@bssm.hs.kr` 정확 일치 규칙을 사용합니다. 학교 계정으로 로그인하고 학년·반을 선택하면 바로 이용합니다. 별도의 반 소속 승인 단계는 없습니다. 학생 관리자도 자기 반 과제를 개인 완료 처리할 수 있으며, 교사 관리자는 조회·관리 기능을 사용합니다.

분리 운영에서는 정확한 프런트 Origin만 허용하고 CORS 프리플라이트·CSRF 검증을 적용합니다. 단기 토큰은 탭 저장소에 두고, 회전하는 갱신 자격은 IndexedDB와 서버 DB의 해시로 유지합니다. 서버 재시작과 터널 주소 변경 후 자동 갱신하며, 로그아웃하면 해당 로그인 묶음을 취소합니다. 사용 중에는 계속 갱신하고 90일 미사용 시 만료됩니다. 비공개 이미지는 인증 요청으로 읽어 Blob으로 표시합니다. 학생별 세션 한도와 전체 세션 용량 제한이 있습니다.

Pages에는 CSP·리퍼러 정책을 넣고 iframe 안의 인증 요청을 차단합니다. 첨부파일은 경로·파일 형식·용량·과제 열람 권한을 확인합니다. SQL은 매개변수를 사용합니다. `.env*`, DB·백업·이미지·비밀키는 공개 산출물에서 제외합니다.

`body-parser`와 `qs`의 확인된 서비스 거부 취약점을 패치했습니다. AI 챗봇 원본은 주석으로 보관하며 관련 실행 경로는 비활성화 상태입니다.

## 검증

Node.js 24에서 다음을 실행합니다.

```sh
cd web
npm ci --ignore-scripts
npm test
npm run check
npm audit --omit=dev
cd ..
node --test deploy/worker.test.mjs scripts/configure-mac.test.mjs scripts/run-mac-tunnel.test.mjs
```

자동 테스트는 임시 HTTP 서버와 DB·Google 대역을 사용합니다. 2026-11-13에는 Pi의 웹·MySQL 상태, 고정 Worker API의 health 응답, 터널 자동 재연결을 확인했습니다. 웹 컨테이너와 터널 서비스를 재시작한 뒤 실제 브라우저에서 수동 Google 재인증 없이 로그인과 달력 건수 표시가 복구됐습니다. 전체 자동 테스트 156개도 통과했습니다. Pi 전원 재부팅과 새로운 Google 인증 흐름 전체는 아직 검증하지 않았습니다. [현재 확인 결과와 과거 기록](docs/VALIDATION.md)을 구분해 확인하세요. 취약점 검사 0건이 미발견 취약점까지 없음을 뜻하지는 않습니다.

기존 배포 자료: [라즈베리파이](docs/RASPBERRY_PI.md), [호스팅 참고](docs/FREE_HOSTING.md). 기존 Railway 데이터와 이미지를 옮길 때는 먼저 원본 백업을 보존하세요.

화면 동작은 먼저 반영하고 서버에서 저장합니다. 실패한 항목만 복원하며, 최근 목록은 계정·소속·역할별 5분 캐시에서 먼저 표시한 뒤 갱신합니다. 일반 학생도 자기 학년·반 공지를 게시하고 본인 공지를 삭제할 수 있습니다. 사용자를 삭제하면 등록 과제·공지와 관련 제출 기록도 같은 트랜잭션에서 삭제합니다.
