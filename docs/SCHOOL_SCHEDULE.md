# 나이스 학사일정

캘린더의 ‘학교 일정’에서 부산소프트웨어마이스터고등학교의 시험·행사를 함께 확인합니다. 토요휴업일·성탄절 등 휴업일·공휴일 이름의 일정은 제외하며, 방학식·개학식이나 공휴일 관련 학교 행사는 유지합니다. 날짜를 누르면 행사 내용과 대상 학년이 표시됩니다. 학교 일정은 읽기 전용이며 과제 등록·드래그·삭제·개인 완료율과 분리됩니다. 학생에게는 자신의 학년 일정, 관리자에게는 선택한 조회 학년의 일정이 표시됩니다.

## 비공개 설정

서버 환경 파일 `.env.pi`의 `NEIS_API_KEY`에 나이스 교육정보 개방 포털에서 발급한 인증키를 설정합니다. 기존 DB·Google·JWT·인증 영역 설정은 유지합니다. Compose의 web 서비스만 다시 만들면 새 키가 적용됩니다. 키를 GitHub, Pages 설정, 브라우저 소스, 오류 로그에 넣지 않습니다. 맥에서 준비한 `.runtime/neis.env`도 Git 배포 대상이 아닙니다.

학교 식별자는 부산교육청 `C10`, 학교 코드 `7150658`로 서버에 고정되어 있습니다. 사용자 요청으로 외부 주소나 다른 학교를 지정할 수 없습니다. DB 스키마 변경이나 기존 과제 데이터 이동은 없습니다.

## 조회·보호

로그인한 사용자가 `GET /api/school-events?month=YYYY-MM`을 요청하면 서버가 공식 나이스 `SchoolSchedule` API를 조회합니다. 학년 권한은 현재 DB 사용자 정보로 확인합니다. 동일 월의 동시 요청은 합쳐지고 성공 결과는 서버 메모리에 1시간 동안 저장됩니다. 다음 조회 때 만료된 결과를 새로 불러옵니다. 서버를 다시 시작하면 이 임시 저장 내용만 비워집니다.

계정마다 10분 동안 30회 조회할 수 있으며, 과제 등록·수정 한도와 별도입니다. 서버 전체 외부 조회는 최대 4개 동시 실행, 월별 최대 500행·5페이지, 페이지당 최대 1MiB, 전체 10초로 제한합니다. 실패하면 30초 동안 외부 재시도를 쉬고 일반 오류만 반환합니다. 키 미설정·제공처 오류가 있어도 기존 과제는 표시되며 ‘다시 불러오기’로 학교 일정만 재시도할 수 있습니다. 나이스의 무인증 5행 샘플을 전체 일정으로 표시하지 않습니다.

일정이 없는 달은 빈 목록을 반환합니다. 시험 여부는 행사명의 ‘고사·시험·평가’로 구분한 강조 표시이며 학교가 제공한 행사명·날짜·학년을 변경하지 않습니다. 나이스 미등록 일정은 자동 생성하지 않습니다. 학교가 변경한 일정은 제공처 반영과 임시 저장 만료 후 확인됩니다.
